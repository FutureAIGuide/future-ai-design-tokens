# Branding

This directory contains branding guidelines, design system documentation, and UI/UX rules for the Future AI Guide project.

## Files

- **DesignSystem_Bricks_2025.md** - Complete design system specification for Bricks Builder with OxyProps integration
- **UI_UX_Rules_and_Prompts.md** - UI/UX principles, super prompts, and design guidelines

## Purpose

These documents define:
- Design token philosophy and usage
- Color palettes, typography, spacing systems
- Component specifications
- Accessibility guidelines
- UI/UX best practices
- Prompt templates for AI-assisted design
