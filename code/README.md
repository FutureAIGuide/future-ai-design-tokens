# Code

This directory contains source code and scripts for the design token system.

## Files

- **csv-to-xlsx.js** - Conversion script that transforms CSV design tokens to Excel format

## Usage

Convert design tokens from CSV to XLSX:
```bash
npm run convert
```

## Development

The script reads from `../design/fg-design-tokens.csv` and outputs to `../design/fg-design-tokens.xlsx`.
